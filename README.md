# Huiatã's Tech Journey

Sim. Como o objetivo é apresentar seu portfólio no Data Show, o prompt precisa orientar o Lovable a construir uma experiência de apresentação profissional, e não simplesmente um currículo em formato de site.

Abaixo está o prompt mestre já estruturado para você copiar e colar diretamente no Lovable. Ele também deixa preparado o espaço para você inserir suas fotos posteriormente.

PROMPT MESTRE — PORTFÓLIO PROFISSIONAL INTERATIVO

Crie um portfólio profissional premium, moderno, tecnológico e altamente visual para Huiatã Ribeiro.

1. OBJETIVO PRINCIPAL

Este projeto NÃO deve parecer um currículo online tradicional.

Quero criar uma experiência digital interativa de apresentação profissional, pensada principalmente para ser projetada em Data Show, televisão ou tela grande, durante uma apresentação profissional.

A experiência deve transmitir:

Tecnologia + Educação + Desenvolvimento de Sistemas + Inteligência Artificial + Inovação.

A primeira impressão deve ser de um profissional moderno, preparado, criativo e conectado com tecnologia.

O visitante deve sentir que está navegando por uma apresentação profissional premium, e não simplesmente lendo um currículo.

O projeto deve funcionar também como portfólio público quando acessado por computador, tablet ou celular.

2. PERFIL PROFISSIONAL

Nome:

Huiatã Ribeiro

Posicionamento profissional:

Instrutor de Tecnologia | Desenvolvimento de Sistemas | Inteligência Artificial

A comunicação deve apresentar Huiatã como um profissional que atua na interseção entre:

Tecnologia;

Educação;

Desenvolvimento de Sistemas;

Programação;

Inteligência Artificial;

Inovação;

Projetos práticos.

Não invente experiências, cargos, empresas, certificações, tecnologias, números, projetos ou resultados.

Utilize exclusivamente informações fornecidas no currículo e posteriormente nas informações fornecidas pelo usuário.

Quando uma informação não estiver disponível, não invente.

3. CONCEITO VISUAL

O conceito visual deve ser:

TECNOLOGIA + ELEGÂNCIA + EDUCAÇÃO + FUTURO

Evitar completamente estética "hacker", excesso de código verde, visual gamer ou aparência infantil.

Quero uma estética semelhante a um portfólio de um profissional de tecnologia de alto nível.

Características:

fundo predominantemente escuro;

contraste elevado;

tipografia moderna;

grandes títulos;

bastante espaço negativo;

elementos geométricos;

efeitos de profundidade;

glassmorphism discreto;

gradientes sofisticados;

iluminação sutil;

animações suaves;

elementos tecnológicos abstratos;

aparência premium;

excelente legibilidade em Data Show.

Não exagerar nos efeitos.

A sofisticação deve vir da composição, tipografia, espaçamento, movimento e hierarquia visual.

4. EXPERIÊNCIA DE APRESENTAÇÃO

Criar dois modos de navegação.

MODO 1 — APRESENTAÇÃO

Data Show;

entrevista;

reunião;

apresentação institucional.

Criar navegação semelhante a uma apresentação interativa.

Permitir:

tecla ArrowLeft para voltar;

tecla Home para início;

tecla End para final;

possibilidade de clicar nos controles;

modo tela cheia quando possível.

Cada seção deve funcionar como um "capítulo".

Adicionar um indicador discreto de progresso na parte inferior da tela.

Exemplo:

Não colocar excesso de informações simultaneamente na tela.

Durante uma apresentação, o usuário deve conseguir explicar cada tela oralmente.
